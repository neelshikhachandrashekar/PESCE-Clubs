# PESCE Clubs – Explore Your Passion

## About the Project

PESCE Clubs is a responsive college club directory website designed to help students explore different interests, discover communities and participate in campus activities.

The project demonstrates how Git, GitHub and GitHub Pages can be used to develop, manage and deploy a website.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality
- Git – Version control
- GitHub – Source code hosting
- GitHub Pages – Website deployment

## Features

1. Home page with an introduction.
2. About section describing the purpose of the website.
3. Club directory with different interest categories.
4. Club search functionality.
5. Campus events section.
6. Interactive Join Us form.
7. Responsive layout for mobile screens.

## Club Categories

- Dance & Music
- Sports & Games
- Arts & Creativity
- Technical Clubs
- Cultural Clubs
- Social Service
- Entrepreneurship
- Literary Clubs

*These are example categories presented in the student project directory.*
